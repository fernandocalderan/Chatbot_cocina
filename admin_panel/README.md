# Admin Panel

## Verificación rápida de flows (2 min)
1) Abrir **Tenants**.
2) Ver badge **PUBLICADO** en “Flow efectivo”.
3) Click en **Probar resolución backend**.
4) Publicar con confirmación (checkbox + escribir `PUBLICAR`).
5) Probar resolución de nuevo.
6) Abrir el widget/chat y verificar que carga el flow correcto.
